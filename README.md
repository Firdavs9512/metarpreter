# Metarpreter

Open port check tool in web UI.


[![Introduction](https://raw.githubusercontent.com/Firdavs9512/metarpreter/master/preview.png)](https://github.com/Firdavs9512/metarpreter)

## Features

- Check if a port is open on a given host
- Check nmap scan results for a given host

## Getting Started

To get started with the project, follow these steps:

1. Clone the repository:

```bash
git clone https://github.com/Firdavs9512/metarpreter.git
```

2. Install frontend packages:

```bash
cd frontend && npm install
```

3. Run the development server: \

```bash
make dev
```

4. Build the tool:

```bash
make build
```
